# GLIC Selenium Framework Context

## Purpose
Review the supplied Selenium Java automation repository and identify migration candidates.

## Verify from actual files
Build configuration (pom.xml/build.gradle), Java/test versions, test runner, WebDriver lifecycle, browser setup, Page Objects, base classes, utilities, locators, waits, assertions, test data, reporting, logging, configuration and CI files.

## Review dimensions
1. Repository layout and build configuration.
2. Selenium/WebDriver lifecycle.
3. Page Object Model and reusable components.
4. Locator reliability and synchronization.
5. Assertions, test organization and coverage.
6. Test data and environment configuration.
7. Reporting, logging and failure handling.
8. Dependencies, CI and migration risks.

## Constraints
- Do not assume files exist based on conventional names.
- Distinguish file-path inventory from inspected source content.
- Do not modify the repository during analysis.
- Do not include credentials or secrets.

## Outputs
Framework inventory, architecture assessment, reusable component inventory, test coverage observations, migration risks, missing files and limitations.
