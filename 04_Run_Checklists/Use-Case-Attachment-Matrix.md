# GLIC Use-Case Attachment Matrix

| Agent | Attach | Expected output |
|---|---|---|
| 1 Framework Review | Repository tree, build files, Java tests, Page Objects, README | Framework assessment |
| 2 Reusable Components | Page Objects, base classes, utilities, factories | Component inventory |
| 3 Migration Design | Assessment, workflow, test cases, standards | Migration design |
| 4 Test Data | Existing data, test-case sheet, data rules | Feature JSON |
| 5 Script Writer | Selenium source, approved design, validated JSON, Playwright context | TypeScript scripts |
| 6 AI Review | Generated scripts, original tests, standards, expected results | Review findings |
| 7 Execution | Target project/workspace, test selection, environment config, authorized runner | Actual execution results |
| 8 Summary | Actual report, logs, screenshots, traces, review findings | Evidence-based summary |

Before attaching: verify repository revision; remove secrets and production data; include source contents when code analysis is required; preserve test IDs; identify placeholders; attach only task-relevant files; obtain approval for writes/execution.
