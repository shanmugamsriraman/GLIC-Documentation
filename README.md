# GLIC Documentation Starter Pack

For the existing HCL AI Force GLIC Selenium-to-Playwright workflow. Replace placeholders with verified project data. Never include credentials, tokens, passwords, private keys or production secrets.

Contents:
- Agent Context templates for common, Selenium and Playwright context.
- AI Force native export/import procedure and tracking template.
- Sample Login migration use-case package.
- Per-agent attachment matrix.

Important: The tracking JSON is documentation metadata only, NOT an AI Force import payload. Obtain the actual JSON schema by exporting a real agent from AI Force.
